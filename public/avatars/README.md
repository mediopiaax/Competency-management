# 캐릭터 이미지 폴더

평가 결과 화면의 대상자 카드에 쓰는 캐릭터 이미지를 여기에 넣습니다.
넣고 나서 화면을 새로고침하면 바로 반영됩니다. (서버를 다시 켤 필요 없음)

## 파일 이름 규칙

| 파일 이름 | 누구에게 쓰이나 |
|---|---|
| `김민준.png` 또는 `2023310452.png` | 이름이나 학번이 같은 대상자 한 명 |
| `1.png`, `stu1_icon.png`처럼 번호가 든 이름 | 전용 이미지가 없는 대상자에게 번호 순서대로 돌아가며 배정 |

- 형식: png, jpg, webp, gif, svg
- 권장: 정사각형, 512×512 이상, 배경이 투명한 png (상반신 캐릭터가 카드 위로 살짝 튀어나오게 배치됩니다)
- 이미지가 하나도 없으면 이름 첫 글자가 든 색 원으로 대신 표시됩니다.
