# 역량평가 서비스 설명서 (영상 제작용)

이 문서는 화면 녹화본으로 **사용 매뉴얼 영상**과 **서비스 소개 영상**을 만드는 사람(또는 AI)을 위한 것이다. 녹화 화면에 보이는 것이 무엇이고 왜 중요한지, 어떤 말로 설명해야 하는지를 담았다. 화면 문구는 2026-10-09 기준 실제 화면 그대로 적었다.

---

## 1. 한 문장으로

**기관이 중요하게 여기는 역량 목록만 넣으면, AI가 평가기준표를 설계해 주고, 그 기준표로 대상자 데이터를 평가해 리포트까지 보여주는 웹 서비스다.**

랜딩 화면의 카피: **"역량만 입력하면, 평가까지 한 번에."**
보조 카피: "기관마다 다른 역량 기준. AI가 평가체계 설계부터 실제 평가까지 이어드려요."

## 2. 누가, 왜 쓰나

| 사용자 | 쓰는 이유 |
|---|---|
| **기관** (대학의 역량·진로 담당 부서 등) | 기관마다 인재상과 역량이 다르다. 그 역량을 무엇으로, 몇 점으로 평가할지 정하는 일(평가체계 설계)이 가장 어렵고 오래 걸린다. 이 서비스는 그 초안을 만들어 주고, 여러 명을 한 번에 평가해 비교해 준다. |
| **학생** | 가고 싶은 기관의 역량을 넣고 본인의 현재 상태를 스스로 점검한다. 쓰는 방법은 기관과 같고, 평가 대상이 본인 한 명이라는 점만 다르다. |

### 풀려는 문제
1. 역량 목록은 있는데, 그걸 어떤 데이터로 어떻게 점수화할지 기준이 없다.
2. 기준을 사람이 처음부터 만들면 오래 걸리고, 만든 사람마다 다르다.
3. 점수만 나오고 "왜 이 점수인지"를 설명하지 못하면 결과를 믿기 어렵다.
4. 데이터가 없는 학생이 낮은 점수를 받는 것처럼 보이면 불공정하다.

### 이 서비스의 답
1. **AI가 초안을 만들고, 사람이 확인해서 확정한다.**
2. **점수 계산은 정해진 규칙으로 한다.** 같은 데이터와 같은 기준표면 결과가 항상 같다.
3. **모든 점수의 근거를 보여준다.** 어떤 데이터가 어떤 기준에 따라 몇 점이 됐는지 계산식까지 열어 볼 수 있다.
4. **"데이터 없음"과 "활동 없음"을 구분한다.** 자료가 부족하면 낮은 점수 대신 "판정 보류"로 표시한다.

## 3. 전체 흐름 (4단계)

화면 맨 위에 항상 네 단계가 보인다. 끝낸 단계는 체크 표시가 된다.

```
① 역량 입력  →  ② 평가기준표  →  ③ 대상자 데이터  →  ④ 평가 결과
```

| 단계 | 사용자가 하는 일 | 시스템이 하는 일 |
|---|---|---|
| ① 역량 입력 | 역량 이름과 설명을 넣는다 (파일·직접 입력·샘플) | 목록을 읽어 정리해 보여준다 |
| ② 평가기준표 | 초안을 훑어보고, 필요한 항목만 눌러 고친 뒤 확정한다 | 역량마다 평가 항목·근거 데이터·점수 기준·비중을 만든다 |
| ③ 대상자 데이터 | 평가할 사람의 데이터 파일(엑셀)을 올린다 | 데이터를 읽고 빠진 것·잘못된 것을 점검한다 |
| ④ 평가 결과 | 전체 비교와 개인별 리포트를 본다 | 점수·등급·강점·아쉬운 점·계산 근거를 만든다 |

**화면 이동 규칙** (녹화할 때 참고)
- 각 단계 화면 **아래에 고정된 큰 파란 버튼 하나**가 다음 단계로 넘어가는 버튼이다.
- 각 단계 화면 **제목 위 왼쪽**에 `홈` 버튼과 `‹ 이전 단계 · ○○` 버튼이 있다.
- 홈 화면 왼쪽 위의 `‹ 처음 화면으로`를 누르면 랜딩 화면으로 돌아간다.

## 4. 꼭 알아야 할 용어

영상 내레이션과 자막에서 아래 용어를 일관되게 쓴다.

| 용어 | 뜻 |
|---|---|
| **작업 공간** | 기관 또는 학생 한 명의 독립된 공간. 역량·기준표·데이터·결과가 공간마다 따로 보관된다. |
| **역량** | 평가하려는 능력. 예: 글로벌, 리더십, 문제해결력. |
| **구분** | 역량을 묶는 상위 분류. 샘플은 "자기개발역량 / 기업 관심 역량 / 교수 관심 역량" 세 가지. |
| **평가기준표** | 역량을 어떻게 점수화할지 정한 표. 이 서비스의 핵심 산출물. |
| **평가 항목** | 한 역량을 나눈 세부 평가 단위. 역량당 2~4개. 예: 글로벌 → "언어 사용능력", "문화적 수용능력". |
| **근거 데이터** | 평가 항목을 판단하는 데 쓰는 실제 데이터. 예: 어학 자격증, 외국어 수업 이수 과목 수. 한 항목에 여러 개를 둘 수 있다. |
| **점수 기준** | 근거 데이터의 값을 점수로 바꾸는 규칙. 예: "4과목 이상 100점, 3과목 85점…". |
| **비중** | 한 역량 안에서 평가 항목이 차지하는 비율(%). 합계가 100이어야 한다. |
| **기본형 / 가점형** | 기본형은 누구나 있을 법한 항목(없으면 0점). 가점형은 드문 실적(있으면 더하고, 없어도 감점 없음). |
| **AI 서술 판정** | 학생이 쓴 활동 기록(글)을 AI가 읽고 레벨 1~5로 판정하는 방식. 원문 인용과 판정 이유를 함께 보여준다. |
| **초안 / 확정** | 초안은 고칠 수 있는 상태. 확정하면 잠기고 버전(v1.0)이 붙는다. 평가는 확정본으로만 한다. |
| **데이터 충족도** | 한 역량을 평가하는 데 필요한 데이터 중 실제로 있는 비율(%). |
| **판정 보류** | 데이터 충족도가 50% 미만이면 등급을 내지 않는 것. 낮은 점수가 아니라 "자료 부족"이라는 뜻. |
| **등급** | S(90점↑) / A(80~89) / B(70~79) / C(60~69) / D(60 미만). 기관이 바꿀 수 있다. |

### 평가기준표의 3단 구조 (영상에서 한 번은 그림으로 보여주면 좋다)

```
역량 (예: 글로벌)
 └ 평가 항목 (예: 언어 사용능력 50% · 문화적 수용능력 50%)
     └ 근거 데이터 + 점수 기준 (예: 어학 자격증 → 환산표 / 외국어 수업 4과목↑ 100점)
```

### 데이터 상태 4가지 (공정성의 핵심)

| 상태 | 뜻 | 점수 처리 |
|---|---|---|
| 값 있음 | 데이터가 있다 | 기준표대로 계산 |
| 활동 없음 | 그 활동을 안 했다고 확인됨 | 0점으로 계산에 포함 |
| 미수집 | 데이터를 모른다 | **계산에서 뺀다 (0점 아님)** |
| 해당 없음 | 이 사람에게 해당하지 않는 항목 | 계산에서 뺀다 (불이익 없음) |

## 5. 화면별 설명

### 5-0. 랜딩 (처음 화면)

- **보이는 것**: 왼쪽에 큰 카피와 세 가지 특징(역량 입력 / AI 평가체계 설계 / 평가 진행 및 결과 확인). 오른쪽에 "누가 사용하나요?" 카드.
- **하는 일**: `기관` 또는 `학생`을 고르고 이름을 입력한 뒤 `시작하기`를 누른다. 예전에 만든 공간은 아래 "이전에 쓰던 공간"에서 고른다.
- **말할 것**: 기관은 여러 명을 한 번에 평가·비교하고, 학생은 본인 상태를 점검한다.

### 5-1. 홈 (진행 현황)

- **보이는 것**: "다음은 ○○ 차례예요" 문장, STEP 1~4 카드, 오른쪽 위 `이어서 하기` 버튼.
- **하는 일**: `이어서 하기`를 누르면 아직 안 끝낸 첫 단계로 간다. 카드를 눌러 원하는 단계로 가도 된다.
- **말할 것**: 어디까지 했는지 한눈에 보이고, 다음에 할 일을 알려준다.

### 5-2. STEP 1 · 역량 입력

- **제목**: "평가하고 싶은 역량을 알려 주세요"
- **입력 방법 세 가지** (카드 세 장)
  - `파일 올리기`: 엑셀(.xlsx)이나 CSV.
  - `직접 입력하기`: 한 줄에 `역량명: 설명` 형식으로 쓴다.
  - `샘플로 시작하기`: 예시 역량 19개가 바로 들어온다.
- **입력 후 보이는 것**: 구분별로 묶인 역량 목록. 역량 이름, 설명, 세부 요소(회색 꼬리표).
- **보조 기능**: `잘못 읽혔나요?`를 누르면 파일의 어느 열이 역량명·설명인지 직접 지정하는 창이 뜬다. 기관마다 파일 형식이 달라도 쓸 수 있다는 뜻이다.
- **다음 단계 버튼**: 아래 `AI로 평가기준표 만들기`.
- **버튼을 누르면**: "평가기준표를 만들고 있어요" 화면이 뜨고 네 문장이 차례로 켜진다 — 역량 목록을 읽고 있어요 → 역량마다 평가 항목을 나누고 있어요 → 근거 데이터를 연결하고 있어요 → 점수 기준을 채우고 있어요. 끝나면 자동으로 평가기준표 화면으로 넘어간다.
- **말할 것**: 필요한 건 역량 이름과 설명뿐이다. 나머지는 AI가 설계한다.

### 5-3. STEP 2 · 평가기준표 (가장 중요한 화면)

**처음 봤을 때 정보가 쏟아지지 않도록 설계했다는 점이 핵심이다. 세부 내용은 누를 때만 열린다.**

- **맨 위**: 기준표 이름, `초안` 또는 `확정 v1.0 · 잠김` 표시.
- **요약 줄**: "역량 19 · 평가 항목 44". 오른쪽에 점검 버튼, `미리 채점`, `⚙ 설정`.
- **구분 탭**: 구분별로 나눠 본다 (자기개발역량 6 / 기업 관심 역량 7 / 교수 관심 역량 6).
- **역량 카드** (한 역량에 하나)
  - 역량 이름과 설명, 오른쪽에 `합계 100%`.
  - 그 아래 평가 항목이 한 줄씩: 항목 이름, 근거 데이터 종류(회색 글씨), 비중(% 와 막대).
  - 꼬리표: `가점`(가점형), `AI 판정`(AI 서술 판정을 쓰는 항목).

**항목을 누르면 → "평가 항목 수정" 창**
- 항목 이름, 비중, "무엇을 보나요" 설명.
- 유형 선택: `기본형` / `가점형`.
- 근거 데이터 목록. 각 근거에 평가 방식 꼬리표와 점수 기준 요약이 보인다.

**근거를 한 번 더 누르면 → 점수 기준 세부 편집**
- 숫자 구간: "4 이상 → 100점, 3 이상 4 미만 → 85점…" 을 직접 고친다.
- 선택지 점수: "회장 100점, 부회장 90점…".
- 어학 환산표: TOEIC·OPIc 등 서로 다른 시험을 0~100점으로 맞춘다.
- AI 서술 판정: 레벨 1~5의 기준 문장을 고친다.

**그 밖의 버튼**
- 점검 버튼(`✓ 문제 없음` / `확인하면 좋은 점 N건` / `고칠 곳 N건`): 기준표의 문제를 자동으로 찾아준다. 비중 합계가 100이 아니거나 구간에 빈틈이 있으면 저장·확정이 막힌다.
- `미리 채점`: 올려 둔 대상자를 지금 기준으로 바로 채점해 본다. 기준을 고치면 결과가 어떻게 바뀌는지 확정 전에 확인할 수 있다.
- `⚙ 설정`: 등급 기준, 판정 보류 기준(충족도 50%), 어학 환산표, 버전, 내보내기.

**다음 단계 버튼**: 아래 `확정하고 다음으로` → "이 기준표로 확정할까요?" 창 → `확정하기`. 확정하면 대상자 데이터 화면으로 넘어간다.

**말할 것**
- AI가 만든 것은 초안이고, 최종 결정은 사람이 한다.
- 전부 볼 필요 없이, 궁금한 항목만 눌러서 확인하면 된다.
- 확정하면 잠겨서 평가 기준이 중간에 바뀌지 않는다. 고치려면 새 버전을 만든다.

### 5-4. STEP 3 · 대상자 데이터

- **제목**: "평가할 대상자의 데이터를 올려 주세요"
- **입력 방법**: `엑셀 파일 올리기`(정해진 양식, 여러 파일 가능) 또는 `샘플 6명으로 해 보기`.
- **올린 뒤 보이는 것**: 대상자 목록. 한 줄에 캐릭터, 이름, 학과·학년, `수집 완료 97%` 막대, 경고·오류 꼬리표.
- **왼쪽 파란 체크**: 평가에 포함할지 고른다. 눌러서 끌 수 있다.
- **한 명을 누르면**: 상세 창. 데이터 상태별 개수(값 있음/활동 없음/미수집/해당 없음), 확인할 점(입력 오류·경고), 기본 정보, 항목별 데이터.
- **다음 단계 버튼**: 아래 `6명 평가하기`.
- **버튼을 누르면**: "6명을 평가하고 있어요" 화면이 뜬 뒤 결과 화면으로 넘어간다.
- **말할 것**: 올리는 순간 데이터 품질을 점검해 준다. 형식이 틀린 값은 추측하지 않고 경고로 알려준다.

### 5-5. STEP 4 · 평가 결과

위쪽 보라색 머리 카드에 "6명의 역량 평가 결과", 사용한 기준표 이름·버전, 평가 시각이 나온다. 오른쪽 `내보내기`로 엑셀·JSON 파일을 받는다.

두 가지 보기를 탭으로 오간다: **전체 비교** / **개별 리포트**.

#### 전체 비교 (2명 이상일 때)

| 영역 | 내용 |
|---|---|
| 요약 카드 4개 | 평가 인원, 전체 평균, 가장 높은 역량, 가장 낮은 역량 |
| 평균 점수 순위 | 대상자별 평균 막대. 절반 넘게 판정 보류된 사람은 순위에서 빼고 "자료 부족"으로 표시 |
| 등급 분포 | S·A·B·C·D·보류가 각각 몇 건인지 막대 그래프 |
| 한눈에 비교 | 대상자 × 역량 표. 색이 짙을수록 점수가 높고, 회색은 판정 보류. 구분 탭으로 전환 |
| 겹쳐 보기 | 세 명까지 골라 방사형 그래프를 겹쳐 본다 |

이름이나 순위 줄을 누르면 그 사람의 개별 리포트로 간다.

#### 개별 리포트

위쪽에 대상자 이름 칩이 있어 사람을 바꿔 볼 수 있다.

1. **프로필 카드**
   - 캐릭터, 이름, 학과·학년, 요약 꼬리표(평균 점수, 80점 이상 역량 수, 판정 보류 수).
   - 말풍선 한 줄 요약: "○○ 역량이 가장 돋보여요 / ○○는 조금 더 채워 볼 수 있어요".
   - Summary: 몇 개 역량을 평가했고 평균·최고·최저가 무엇인지.
   - 오른쪽: 구분별 평균(선 위의 점).
   - 아래: **Strength(강점)** 과 **Painpoint(아쉬운 점)**.
2. **역량 흐름**
   - 점수가 높은 역량부터 낮은 역량까지 이어 본 곡선. 얼굴 표정이 점수대를 뜻한다 (😆 90↑ · 😊 80↑ · 🙂 70↑ · 😐 60↑ · 😟 60↓ · 🫥 보류).
   - 아래 **Painpoint → Solution** 카드: 점수가 낮은 항목과, 무엇을 얼마나 올리면 몇 점이 되는지.
3. **역량 지도**
   - 방사형 그래프와 역량별 점수 막대·등급. 구분 탭으로 전환.

**역량(얼굴 또는 줄)을 누르면 → 계산 근거 창**
- 점수, 등급, 데이터 충족도, 신뢰도.
- "어떻게 평가했나요": 평가 항목마다 사용한 데이터 → 적용한 기준 → 점수.
- AI 서술 판정이 있으면: 판정 레벨, 적용한 기준 문장, **학생 원문 인용**, 판정 이유.
- 계산식과 `검산 일치` 표시.

**말할 것**
- 점수만 보여주지 않는다. 왜 그 점수인지 끝까지 따라가 볼 수 있다.
- 자료가 부족하면 낮은 점수를 주지 않고 판정을 보류한다.
- 개선점은 "더 노력하세요"가 아니라 "무엇을 얼마로 올리면 몇 점"으로 구체적이다.

## 7. 영상에서 강조할 메시지 (우선순위 순)

1. **역량만 넣으면 평가체계가 나온다.** 가장 어렵고 오래 걸리는 설계 단계를 AI가 초안으로 만들어 준다.
2. **AI는 초안, 결정은 사람.** 모든 항목과 점수 기준을 확인하고 고칠 수 있으며, 확정은 사람이 한다.
3. **모든 점수에 근거가 있다.** 어떤 데이터 → 어떤 기준 → 몇 점인지, 계산식과 검산까지 보여준다.
4. **데이터가 없다고 불이익을 주지 않는다.** 미수집은 0점이 아니라 계산에서 빼고, 자료가 부족하면 판정을 보류한다.
5. **결과가 흔들리지 않는다.** 숫자·목록 항목은 정해진 규칙으로 계산하므로 같은 입력이면 항상 같은 점수다. 확정본은 버전으로 고정된다.
6. **한눈에 보이는 리포트.** 여러 명 비교부터 한 명의 강점·개선점까지 그래프와 카드로 정리된다.
7. **기관도, 학생도.** 기관은 여러 명을 평가하고, 학생은 스스로 점검한다.

## 8. 말하면 안 되는 것, 조심할 것

- **현재 녹화 환경은 데모 모드다.** AI가 아직 연결되지 않아 화면 곳곳에 `데모` 표시가 나온다.
  - 평가기준표 초안과 AI 서술 판정은 **데모용 규칙**이 대신 만든다.
  - 숫자·목록 항목의 점수는 데모가 아니다. 올린 데이터로 실제 계산한 값이다.
  - 영상에서 "AI가 실시간으로 만든 결과"라고 단정하지 말 것. 소개 영상에서는 "AI가 평가체계를 설계해 준다"는 제품 설명으로, 화면은 "예시 화면"으로 다루는 것이 안전하다. `데모` 표시를 편집으로 가릴지는 제작 의뢰자가 정한다.
- **샘플 데이터는 가상 인물이다.** 실제 학생 정보가 아니다.
- **점수 기준의 기본값은 임의로 정한 값이다.** 구간 경계, 점수, 어학 환산표는 기관이 반드시 검토해 고쳐야 하는 출발점이다. "검증된 기준"이라고 말하지 말 것.
- **"AI가 평가한다"고 뭉뚱그려 말하지 말 것.** AI가 하는 일은 두 가지뿐이다: ① 평가기준표 초안 설계, ② 서술형 기록의 레벨 판정. 점수 계산 자체는 규칙으로 한다.
- **판정 보류를 "불합격"이나 "낮은 등급"으로 표현하지 말 것.** "자료가 부족해 등급을 내지 않았다"가 정확하다.
- **특정 대학 이름을 서비스의 전제로 말하지 말 것.** 샘플 역량 목록은 예시일 뿐이고, 어떤 기관이든 자기 역량 목록으로 쓸 수 있다.
- **아직 없는 기능**: 로그인·권한 관리, 평가기준표 엑셀 내보내기·불러오기(JSON만 가능), 버전 간 비교, 개선점에 맞는 프로그램 추천. 영상에서 있는 것처럼 말하지 말 것.

## 9. 말투와 표기

- 화면 문구는 "~해요" 체다. 내레이션과 자막도 같은 톤으로 맞추면 자연스럽다.
- 버튼 이름은 화면 그대로 쓴다: `AI로 평가기준표 만들기`, `확정하고 다음으로`, `6명 평가하기`.
- "채점기준표", "루브릭" 대신 **"평가기준표"** 로 통일한다.
- "학생" 대신 **"대상자"** 를 기본으로 쓴다(화면 표기). 학생이 직접 쓰는 경우를 설명할 때만 "학생"을 쓴다.
- 서비스 이름은 화면 왼쪽 위 표기대로 **"역량평가"**.

## 10. 영상 구성 제안

### 서비스 소개 영상 (60~90초)

| 구간 | 내용 | 화면 |
|---|---|---|
| 0~10초 | 문제 제기: 역량은 정했는데, 어떻게 평가할지가 막막하다 | 랜딩 카피 |
| 10~25초 | 역량만 넣으면 AI가 평가기준표를 설계한다 | 역량 입력 → 만드는 중 화면 → 평가기준표 |
| 25~40초 | 사람이 확인하고 고쳐서 확정한다 | 항목 수정 창, 점수 기준 펼치기, 확정 |
| 40~55초 | 데이터를 올리면 바로 평가된다 | 대상자 목록 → 평가 중 화면 |
| 55~80초 | 한눈에 비교하고, 한 명씩 근거까지 본다 | 전체 비교 → 개별 리포트 → 계산 근거 창 |
| 마지막 | 카피: "역량만 입력하면, 평가까지 한 번에." | 랜딩 또는 로고 |

### 사용 매뉴얼 영상 (3~5분)

6장의 녹화 시나리오 순서를 그대로 따르고, 단계가 바뀔 때마다 화면 위 단계 표시를 짚어 준다.

1. 시작하기 (작업 공간 만들기)
2. STEP 1 역량 입력 — 세 가지 입력 방법
3. STEP 2 평가기준표 — 훑어보기 → 항목 고치기 → 점검 → 확정
4. STEP 3 대상자 데이터 — 올리기 → 점검 결과 보기
5. STEP 4 평가 결과 — 전체 비교 → 개별 리포트 → 계산 근거 → 내보내기
6. 알아두면 좋은 것 — 판정 보류의 뜻, 새 버전 만들기, 홈·이전 단계 버튼
